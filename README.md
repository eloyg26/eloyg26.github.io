# Equality — Finanzas personales (scaffold)

Proyecto base para un dashboard de finanzas personales con React + Vite.

Rasgos principales:
- Dashboard con patrimonio neto, variación mensual y gráficos.
- Gestión de activos: añadir, editar precio y eliminar.
- Tema claro/oscuro y diseño responsivo minimalista.

Instalación y ejecución local:

```bash
npm install
npm run dev
```

Abre `http://localhost:5173` (vite por defecto).

Dependencias sugeridas: `chart.js` y `react-chartjs-2` para los gráficos.
